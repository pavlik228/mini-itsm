# 0005. Время через Clock

- Статус: Accepted
- Дата: 2026-10-14

## Контекст

Clock даёт наносекунды, Postgres хранит микросекунды — значение после чтения из БД не совпадало с исходным.

## Решение

- Время только через бин `java.time.Clock`.
- createdAt усекается до MICROS в домене (точность TIMESTAMPTZ).

## Рассмотренные варианты

- **Instant.now()** — отвергнут: нетестируемо.
- **Усечение в БД/маппинге** — отвергнут: правило оказывается вне домена.

## Последствия

- \+ Детерминированные тесты.
- \+ Значение после чтения из БД равно исходному.
- − Любое время только через Clock.
