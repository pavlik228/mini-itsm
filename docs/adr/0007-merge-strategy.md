# 0007. Стратегия merge

- Статус: Proposed
- Дата: 2026-10-14

## Контекст

Слайс — единица поставки и отката. Коммиты test: и feat: — доказательство test-first, их нужно сохранить с исходными SHA.

## Решение

- Только merge commit: squash и rebase выключены в настройках репозитория и в ruleset.
- Слайс = один merge-коммит, откат — `git revert -m 1`.

## Рассмотренные варианты

- **Squash** — отвергнут: теряются отдельные коммиты test:/feat: — доказательство test-first.
- **Rebase** — отвергнут: новые SHA ломают ссылки аудита.

## Последствия

- \+ Граница слайса видна, откат одним `revert -m 1`, SHA сохраняются.
- − Нелинейная история.
