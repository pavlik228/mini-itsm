# 0001. Ведём ADR

- Статус: Accepted
- Дата: 2026-10-14

## Контекст

Агенты не видят истории решений и «упрощают» неочевидный код. CLAUDE.md должен оставаться коротким.

## Решение

Одно решение — один файл в формате MADR-lite. Принятый ADR не редактируется: изменение оформляется новым ADR со ссылкой «Supersedes», старый получает «Superseded by».

## Рассмотренные варианты

- **Только CLAUDE.md** — отвергнут: файл раздувается, в нём нет «почему».
- **Только коммиты/PR** — отвергнут: причину не найти, нет рассмотренных альтернатив.

## Последствия

- \+ Решения переживают сессии агента и смену людей.
- \+ Context pack ссылается на ADR вместо пересказа.
- − Время на написание и ревью.
- ADR в статусе Proposed не действует, пока человек не поставит Accepted.
